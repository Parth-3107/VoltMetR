# VoltMetR

Machine Learning based electricity consumption forecasting using real-world Indian residential electricity data.

## Project Status

Currently in the data exploration and preprocessing phase.

## Planned Pipeline

IIT Bombay Residential Electricity Data
→ Data Cleaning
→ Exploratory Data Analysis
→ Feature Engineering
→ Baseline Model
→ Machine Learning Models
→ Model Evaluation
→ FastAPI
→ React Dashboard

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- FastAPI
- React
- TypeScript
